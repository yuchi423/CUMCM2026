# D-012 第三问三路线实测结论（待审查）

> 2026-09-12更新：用户已选择方向2为主模型。下文保留原比较阶段记录；当前选择及结果入口见 `memory/decisions/D-013-q3-main-confirmed.md` 与 `deliverables/q3/README.md`（仓库相对路径）。


统一运行2025年2—12月334天，1月从6000kWh连续热启动。控制组和三条路线使用相同负载预测、实际执行器、逐次调整账本和线性预报映射。完整指标见`experiments/q3-models-20260911-04/model_report.md`。

现金费用：仅0时预报1652.87万元；状态反馈1459.53万元；方向1点预报滚动1451.09万元；方向2提前期余量1385.22万元；方向3连续误差场景1369.73万元。库存调整后排序不变。数值最低为方向3，相对仅0时预报降低283.15万元。

论文主线暂推荐方向2，方向3保留为增强项。理由是方向3相对方向2全年只再降低15.49万元，9—12月仅降低0.40万元，却需要为每个更新时刻生成多组候选并进行场景回放。该推荐是竞赛效用判断，不修改“方向3为本轮数值冠军”的事实。

新增PV预报的价值不能用1652.87与1451.09直接相减：状态反馈本身已降低193.34万元；在同样允许重算的情况下，最新PV点预报相对沿用0时PV曲线再降低8.45万元。余量/场景的主要收益来自减少5倍紧急购电。

整点预报映射是关键口径。线性映射对实际PV总体MAE为142.60kW，阶梯映射为332.28kW；阶梯点预报路线费用高190.78万元。证据支持采用线性映射，但它仍是建模近似，不写成题面明文。

独立审计复算315360条实际执行记录和7650次计划版本，误差均在1e-6容差内。第三问未使用DP。当前结果是时间顺序回测，不是外部新数据盲测；未生成result3.xlsx，未批准为论文最终模型。
