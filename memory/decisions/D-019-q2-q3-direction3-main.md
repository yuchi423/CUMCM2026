# D-019 第二问与第三问采用方向3

2026-09-13，用户明确确认第二问、第三问均以各自模型菜单中的方向3作为主方向。本决策替代第三问D-013的方向2主模型选择。

第三问方向3对应 `rolling_scenario`：使用最近8条连续净负荷预测残差轨迹生成候选计划，并以场景平均库存修正费用加0.25倍90%尾部超额评分。既有实验 `experiments/q3-models-20260911-04` 已完成334天运行和独立审计，因此直接提取为 [`deliverables/q3`](../../deliverables/q3/README.md)；没有重新调参。现金总费用13,697,255.50元，库存修正指标13,697,787.53元。

第二问方向3指“保持时间相关性的供需场景＋尾部费用控制”。当前仓库只完成确定性、分位数余量和18种预测/库存候选；没有找到第二问场景/CVaR的同等级334天实跑结果。因此本决策确认建模路线，但不把现有 `combined` 结果改名为方向3，也不修改 `result2.xlsx` 数值。第二问需另立任务实现、预声明参数并与当前基线在同一因果执行器上比较后，才能成为正式数值结果。

两问的方向3均须保留连续误差结构、实际执行的信息边界和高费用尾部指标。第三问当前实现采用固定候选计划加因果场景回放，避免场景内电池完美预知；第二问后续实现也必须满足这一要求。
