# D-014 Task 4/Task 5 主线确认

## 决策

推荐论文主线为：

- Task 4（问题4-2）：方向2，逐日电价驱动的稳健日前优化；
- Task 5（问题4-3）：方向2，逐日电价下的余量滚动调整。

## 依据

问题4增加的是附件4中的“日期×时段”电价输入，不是模型可以自由选择的电价变量。题面没有明确未来价格的发布时间或锁价机制，因此主线暂采用“当天完整电价曲线在0:00可获得”的建模假设，并在论文中单独声明。

Task 4 在第二问 `combined` 方案上替换逐日电价，Task 5 沿用第三问已选 `rolling_margin`，同时保留历史误差余量、储能约束、因果执行器和已确认的调整账本。两问只增加日期相关价格层，便于解释问题2→问题3→问题4的递进关系。

## 备选与限制

若论文最终采用“未来价格在0:00未知”的信息解释，则切换到历史价格预测基线，并把价格风险控制作为对照。方向3的价格情景或联合场景只作为增强路线，须在方向2稳定运行后通过同一实际价格轨迹、费用分解和分月稳定性验证。
