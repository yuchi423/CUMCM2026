# D-006：修正光伏盈余时错误禁止网电补充充电

- 状态：accepted bug fix；日期2026-09-11；任务T-004。
- 触发：用户指出其他讨论费用35126.95元，随后要求停止查讨论、直接核查计算。独立重新构造的标准LP在相同附件、效率、功率和初末库存下复现35126.948589元。
- 根因：此前实现额外写入“PV盈余时g=0、总充电c不得高于PV盈余”，且将优先充光伏错误校验为“总充电只能来自光伏”。用户仅要求光伏先供负载再充电，题面亦未禁止PV有盈余时购买低价网电补充充电。原35859.32元是额外限制下的结果，不再作为本题目标的最优值。
- 正确口径：将光伏充电cp与总充电c区分。光伏先满足负载，再按容量/功率尽量吸收盈余，cp=surplus-spill；剩余充电能力允许网电补充，c=cp+cg。不允许弃光同时用网电替代光伏；不售电；充放电互斥。
- 约束修复：删除g=0和c≤surplus；优先充光伏的逻辑施加于cp。PV充满容量分支使用E_end−0.9*g=Emax，保证不能先以网电填满后弃光。
- 未变：区间末值主口径、单程效率各0.9、E0=E144=6000kWh、安全范围1200—10800kWh、交流侧充放电最大5000kW。
- 证据：experiments/q1-contract-tests-20260911-03；独立LP与保存的严格MILP方案费用差7.3e-12元。新增100度PV+100度网电→162度输出、费用10元的手算回归测试；旧禁购电实现会错过该可行方案。
- 纠错边界：旧LP和MILP一致并不能验证题意，因为两者共享了同一多余约束；原独立能量核算只能保证输出对该错误规格可行。本次另用不导入原约束构造器的scripts/independent_q1_check.py交叉核对。
- 替代：D-005及旧报告中“电网仅在非盈余时段充电”的部分由本记录替代。原始运行01/02保留但加INVALID说明。A5的标签错位事实仍成立，具体数值以03为准。
