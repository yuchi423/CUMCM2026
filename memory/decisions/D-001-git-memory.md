# D-001：以 Git 文件作为共享记忆

- 日期：2026-09-10
- 状态：accepted
- 依据：团队要求在账号额度不足时，其他队员 pull 后接着工作。
- 决定：AGENTS.md 统一协议；PROJECT 保存稳定约定；每任务 JSON 保存当前状态；独立 Markdown 文件保存决策和交接；实验记录绑定代码提交和数据哈希。
- 原因：可版本化、可离线读取、与代码一起传递，无需共用账号或额外记忆服务。任务分文件降低并行冲突。
- 未采用：共享单一超长聊天记录（检索成本高且难核验）；外部向量库（增加服务和权限依赖）；多人同时改一个总状态文件（冲突集中）。
- 局限：只能恢复已保存状态；Git 推送不是任务互斥锁；外部数据和运行中进程需另行恢复。
- 重启条件：记忆量大到按索引读取仍难检索时，增加自动索引，但保留 Git 原文作为依据。
