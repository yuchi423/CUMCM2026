# 2. Structural Screen

## Baseline：确定性线性规划（KEEP）

### 数学形式

以下公式均以Q1-A1至Q1-A5获批为前提。目前仅作结构推导，未编码求解。

设t=1,…,144，Δt=1/6 h。附件1的负载功率和光伏预测功率分别为L_t、V_t，价格为p_t。定义区间电量l_t=L_tΔt、v_t=V_tΔt。

决策量：g_t为购电量，c_t为交流侧充电输入，d_t为交流侧放电输出，s_t为未被利用的盈余，E_t为区间末电池储电量；上述单位均为kWh。

目标函数：

$$\min C=\sum_{t=1}^{144}p_tg_t.$$

供需平衡：

$$g_t+v_t+d_t=l_t+c_t+s_t.$$

储能动态：

$$E_t=E_{t-1}+\eta_c c_t-\frac{d_t}{\eta_d},\qquad \eta_c=\eta_d=0.9.$$

约束：

$$g_t\ge0,\quad s_t\ge0,\quad 0\le c_t,d_t\le5000\Delta t=\frac{5000}{6},$$

$$1200\le E_t\le10800,\qquad E_0=E_{144}=6000.$$

一次优化覆盖整天，不按144个独立时段贪心决策。购电量g_t已经是kWh，费用中不得再次乘Δt。

### 为什么LP结构成立

- Task Fit：决策变量直接生成题目要求的购电、储能和费用输出。
- Data Support：附件1给定全部确定性输入，无须训练额外预测器。
- Key Assumptions：固定效率、线性费用、上述时间及盈余口径；假设改变可能改变约束和最优解。
- Identifiability：无需从一天数据反演储能参数。设备参数是输入；等费用多解不等同于参数不可识别。
- Simpler Alternative：无储能规则g_t=max(l_t−v_t,0)、s_t=max(v_t−l_t,0)、c_t=d_t=0、E_t=6000可作可行费用对照，但不替代最优调度。

### LP互斥最优解的条件性证明

在Q1-A4允许盈余无额外上限、无额外成本，且0<η_cη_d≤1的条件下，假设某时段c_t、d_t均为正。令κ=η_cη_d，并取：

$$\delta=\min(c_t,d_t/\kappa),\quad c'_t=c_t-\delta,\quad d'_t=d_t-\kappa\delta,$$

$$s'_t=s_t+(1-\kappa)\delta,\qquad g'_t=g_t.$$

至少一个充放电量变为零，两者均非负且不增加功率。储能增量保持不变，因为η_cδ=κδ/η_d；供需两边同时减少κδ，因此平衡仍成立。盈余不减且仍满足s'_t≥0；储电量轨迹、日末条件和购电费均不变。

逐时应用即可把任意LP可行解变成同费用的互斥可行解，因此在这些条件下LP与互斥MILP具有相同最优目标值。**这是条件性代数结论，不是实际运行证据，也不表示任意求解器直接返回的LP解天然互斥。**

若新增盈余上限、仅允许特定来源弃用、弃电成本、非线性效率或模式约束，必须重新检查此证明，不能直接复用。

## Candidate A：显式互斥MILP（KEEP）

保留相同输入、目标及状态约束，增加z_t∈{0,1}：

$$c_t\le\frac{5000}{6}z_t,\qquad d_t\le\frac{5000}{6}(1-z_t).$$

- 直接保证每10分钟只有一种充放电模式，新增144个二元变量，不引入需估计的物理参数。
- 复杂度的价值在于处理LP等价条件不成立时的互斥约束；不能以“比LP费用更低”作为采用条件。
- 在当前提议口径下可作 formulation 对照。需报告求解状态、可行解、目标界与最优性间隙；限时可行解不得称为已证最优。

## Candidate B：费用最优后的吞吐量择优（RISK，条件保留）

先求一级最优费用C*，再在C≤C*+ε_C范围内最小化Σ(c_t+d_t)。严格保费应取ε_C=0；数值实现如需容差，预先限定ε_C≤0.01元，并报告实际费用增量。

只有一级解出现等价循环或同费用多解影响解释时才启用；代数消环足够时无需再求解。它是同一LP/MILP内核的择优步骤，不是独立预测或风险模型。此阶段不优化开关次数，不添加题目未规定的寿命价格。

## Rejected Models

- 用评分排序代替购电和储能优化：不能生成受跨时段约束的最优方案，`REJECT`。
- 利用其他问题附件的事后实测替换问题1光伏预测：更改问题1输入目标，`REJECT`。
- 引入未给出的售电收入、紧急购电罚价或自由初始库存：改变题目目标/条件，`REJECT`。
- 当前没有采用遗传算法、强化学习或随机场景的必要证据，不进入本轮候选；本题线性结构无需用这些方法增加搜索不确定性。
