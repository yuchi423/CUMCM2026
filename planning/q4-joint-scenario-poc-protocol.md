# 问题4-2匹配价格—供需残差情景 Cheap PoC 协议

日期：2026-09-12。依据D-017的继续修改授权，D-015双层目标与回退不变。本协议在看到本轮结果前冻结。

## 1. 新信息与候选结构

上一轮的逐日事后最优权重在验证期和评估期都优于7日均值与固定价，说明低维候选普通购电计划存在可选择空间；28日历史总费用选择失败，说明需要把当天供需预测与价格、负载、光伏误差的共同变化纳入评分。

每天0点先用相同的 `combined` 供需预测、0.8分位余量和当前SOC，分别生成固定价格、五档固定—14日价格组合及7日价格对应的普通购电计划。随后只在这些已经满足原计划约束的方案中选择，不修改余量或物理口径。

### Candidate A：负荷情景选择器

取此前28个已结束日的负载和光伏预测残差，叠加到当天负载、光伏预测上，形成28个供需情景；全部使用当天14日均值价格。用原贪心执行器回放每个候选普通计划，按平均库存调整费用选择计划。结构 `KEEP`。

### Candidate B：匹配联合情景选择器

在Candidate A基础上，把同一历史日的价格预测残差也叠加到当天14日均值价格上，使价格误差与供需误差按历史日期匹配。每个候选在28个情景上的平均实际费用最低者用于当天。结构 `RISK`：若收益来自价格残差的边际分布，而非与供需残差的匹配关系，则不支持联合情景解释。

### Controls

- `shuffled_scenario_selector`：价格残差相对供需残差固定循环错开7日，保留边际分布但破坏日期匹配；
- `rolling_cost_selector`：上一轮28日历史总费用规则；
- `oracle_plan_daily`：看到当天实际价格与供需后从相同计划族选最低费用，只作上界；
- `fixed`、`mean7`、`mean14`：共同基线。

## 2. 情景构造

对目标日 \(d\) 和历史日 \(h<d\)：

\[
L^{(h)}_{d,t}=\max\{0,\hat L_{d,t}+(L_{h,t}-\hat L_{h,t})\},
\]

\[
V^{(h)}_{d,t}=\max\{0,\hat V_{d,t}+(V_{h,t}-\hat V_{h,t})\},
\]

\[
p^{(h)}_{d,t}=\max\{0.01,\bar p^{14}_{d,t}+(p_{h,t}-\bar p^{14}_{h,t})\}.
\]

所有历史预测 \(\hat L_h,\hat V_h,\bar p_h^{14}\) 都按历史日当时可得到的数据重建。联合情景使用同一个 \(h\)；错位对照把价格残差换成窗口内循环后移7日的残差。情景只用于0点选择普通计划，真实当天未来数据不进入任何可执行候选。

## 3. PoC与裁决

使用原六个14天窗口和共同窗口初始SOC。开发期比较负荷情景与联合情景；相差不超过0.5%时选择更简单的负荷情景。验证期、评估期冻结模型。

Scientific Target Failure Condition：选中方案未能在validation和evaluation分别同时比 `mean7` 与 `fixed` 至少降低0.1%的库存调整费用，或联合情景被选中但不能优于错位情景对照，则判定稳定费用目标失败。

Algorithm Failure Condition：未来信息扰动改变可执行选择、情景历史包含目标日或未来、情景/选择不能独立重建、能量/费用/SOC/功率误差超过1e-6或求解失败。

完成8方法×84天、28情景回放、独立审计和报告后停止。成功则返回Human Model Gate申请334天正式运行；失败则说明低维候选计划选择仍不能利用历史情景稳定识别当天最优计划，Workflow Recheck转向直接的两阶段随机购电优化，并重新审查其日内非预见性约束。
