# 问题2 PoC：获批口径与预先声明的试验设置

任务T-005-codex-q2-poc。用户本轮明确要求运行问题2PoC，并确认前述B0—B8无问题，本轮视为HUMAN TARGET GATE已通过。仓库没有单独的B0—B8编号文件，以本轮对话和[confirmed-contract.md](confirmed-contract.md)的实际内容为准，不重复请求已获授权。

## 1. Task Contract Check

- Minimum Deliverable：本轮先交付2月1—14日的0时购电计划、实际储能、紧急电量与费用、对照及逻辑审阅；题目最终334天和四个指定日期仍须后续完整交付。
- Scientific Interpretation Goal：NOT REQUIRED；本轮检查可执行性，不证明自然机制或全年最优。
- Scientific Fallback Deliverable：NOT REQUIRED。算法上保留点预测基线，余量策略无收益则不替换基线。
- 输入：附件1固定价格、附件2历史负载/光伏、题给储能参数；附件3/4不使用。
- 计量：10分钟，区间末值主口径，交流侧充放电；单程效率各0.9；储电量1200—10800，功率5000 kW，1月1日初始6000 kWh。
- 0时计划固定，按计划量收费，未用不退款；缺口以5倍当时价格补齐。盈余不售电。
- 光伏先负载后尽可能储存，剩余才弃光；仍有充电空间时允许已计划的普通网电补充充电。分开记录PV充电、网电充电、弃光和未用计划电量。
- 实际电量跨日承接，不每日重置或强行恢复6000。禁止未来实测参与当前计划/执行。

## 2. Structural Screen

Baseline：过去7天同刻算术均值预测负载/PV，确定性日前优化，再按统一实时规则执行。KEEP。

Candidate A：在相同点预测上，叠加过去28天真实滚动预测净负载残差的0.8分位数正向余量；每小时合并6个时点估计，再还原144区间。RISK，首轮运行。余量只加在规划需求上，本轮不额外施加SOC备用，避免重复覆盖和多模块同时变化。

场景、CVaR、DP及不同实时控制器不在本轮。0.8不是由5倍价格推导出的理论最优值，也不是经过2月调参得到的值。

日前内核：先求LP松弛，逐条审核充放电互斥与强制吸收PV；不满足时切换严格MILP。仅当LP本身满足严格约束时才把它视为该次确定性规划的最优证据。不直接沿用增加弃光的消环变换。

## 3. Target Validity Gate（本轮已批准进入PoC）

前述B类语义按用户确认执行。以下具体数值与实现属于本次PoC预先声明的设计，不冒充题面参数：

| 设置 | 本次规则 | 审阅重点 |
| --- | --- | --- |
| 范围 | 1月1—31日统一基线热启动；2月1—14日比较两策略 | 不以两周结果声称全年有效 |
| 冷启动 | 1月1日无普通购电计划，用当前PV、初始电池和紧急电满足负载；从1月2日使用已有历史预测 | 首日不读取未来来预测；其费用仅列热启动，不计2月主指标 |
| 公平起点 | 两候选共享1月真实回放得到的2月初电量 | 不手填有利起点 |
| 预测计划终端 | 每天预测方案末端目标6000 kWh | 这是策略设计；真实执行末端不强制达到，也不补电重置 |
| 实时动作 | PV优先供负载；普通计划电补剩余负载；有盈余尽可能充电且PV先充；有缺口放电至安全下限，不足再紧急补购 | 本轮选用不额外留SOC备用的简单控制器；它不被声称动态最优 |
| 紧急用途 | 只填当前负载缺口，不给电池充电 | 不制造充电缺口或主动使用紧急电套利 |
| 观测近似 | 当前区间供需可用于快速平衡；未来区间不可用 | 区间级理想响应，不证明秒级动态安全 |
| 库存比较 | 报原始现金费用和期末储电量；另报按v=0.9×均价计算的K+v(E_start−E_end)诊断，并用最低/最高日内价格检查敏感性 | 库存价值不是题目收费，不能并入正式购电账单或伪装实收收益 |

主要混淆：未来数据、共享错误约束、额外初始库存、漏算计划电费、期末库存不一致、修改执行器后错误归因于余量。

诊断预声明：未来数据扰动不改变此前预测/计划；当前后续区间扰动不改变此前动作；独立重读原始输入核算状态、费用、互斥、PV优先、紧急用途和跨日连续；手算成本、效率、网电补充PV充电与小实例枚举；完全准确预测下执行与规划一致性。

失败条件：任何未解释物理/信息/结算违规否定实现；候选无总费用优势或优势依赖库存计价时不批准替换基线。能量容差1e-6 kWh、功率1e-5 kW、费用重算0.01元。比较用相同输入、控制器与边界，不按结果改参数。
