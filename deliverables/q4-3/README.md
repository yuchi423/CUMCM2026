# 问题4-3方向3正式结果包

本包对应问题4-3正式主模型 `rolling_scenario_mean14`。模型延续问题3方向3的连续残差场景滚动框架，在0:00、6:00、12:00、18:00更新计划；电价使用目标日前最多14个完整日期的同刻均值预测，真实附件4价格只用于结算。

统计期为2025-02-01至2025-12-31，共334天；2025年1月从官方6000 kWh初始SOC开始热身。正式期现金总费用为14,432,279.80元，库存修正费用为14,432,805.82元；相对旧余量基线现金费用减少171,182.49元（1.172%），紧急购电量减少24,822.21 kWh。

334天日费用CVaR90为73,458.35元，按最贵33天加第34天40%权重计算。旧值73,323.89元已撤回；这项统计修正不改变逐日费用、计划、SOC、总费用或工作簿数据。

## 文件

- `summary_tables.csv`：总费用、购电量、SOC和基线比较。
- `monthly_summary.csv`、`periods.csv`、`paper_dates_summary.csv`：月度、阶段和指定日期汇总。
- `model_report.md`：模型定义、验证、失败边界和限制。
- `audit_summary.json`、`solver_audit_summary.json`、`workbook_audit.json`：独立账本、求解器和官方工作簿审计。
- `cvar_correction.json`：旧风险汇总到精确经验CVaR的逐表修正记录。
- `figures/`：三张论文图的PNG与PDF版本。
- `manifest.json`：来源实验、工作簿和本包文件哈希。

官方提交工作簿位于 `output/result4-3.xlsx`。其四张工作表、顺序和表头与官方模板一致；已逐格核对111999个填数单元，最大数值差异为0。

## 复现

在仓库根目录运行：

```text
python final_run/q4_3_scenario/main.py <新的运行目录>
```

输出目录必须不存在。完整逐槽账本和工作簿中间数据可由入口重建，没有重复放入Git结果包。

## 使用限制

结果属于因果时间顺序回放，不等于外部盲测。问题4未明确未来电价的公布时刻，因此本包采用“历史同刻均价决策、真实价结算”的保守假设。正式期初SOC继承1月热身后的2119.622103 kWh；修改价格信息边界或初始SOC时必须重新运行。

本包只实现逐次调整费，只优化到当天24:00。它没有验证初始—最终一次计费，也不能称为跨午夜24小时滚动优化。旧84天实验仍为Scientific FAIL；全年结果支持当前交付选择，但不能单独完成“连续误差相关性导致收益”的机制归因。
