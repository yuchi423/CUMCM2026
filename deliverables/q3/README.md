# 第三问方向2：主模型结果

2026-09-12用户选择方向2作为论文主模型，方向3保留为对比与增强。这里整理已审计实验 `experiments/q3-models-20260911-04` 的 `rolling_margin`，未重新求解、未调整参数。此入口是模型结果包；尚未填入赛题的 `result3.xlsx` 模板。

## 模型思路

延续第二问的“负载预测＋历史误差余量＋储能优化”，第三问增加0/6/12/18时光伏预测更新、当前真实储电量反馈及逐次计划调整费用。未使用DP；内部计划采用LP，物理优先规则不满足时转MILP求解。

1. 负载采用过去35天同星期均值；同星期样本少于2个时退回过去7天均值，当日预测在0时固定。
2. 光伏采用当前发布的最新预报，从发布时刻最近已观测值到未来整点做线性插值，转换为10分钟电量。这是模型近似。
3. 按同一发布时间，取过去28天净负载预测残差，每小时合并6个时点，取0.8分位并截断为非负，作为负载侧余量。它不是整日80%供电可靠性的保证。
4. 以当前实际储电量求解新的购电计划，并与“保持上一版剩余计划”比较。候选评分使用相同因果执行规则下的预测费用，加期末库存价值修正；方向2不使用多情景尾部评分。
5. 真实执行沿用光伏先负载、再充电、再弃光规则，网电可补充充电；缺口先放电再按5倍价格紧急购电。储电量跨日连续。

**本包窗口：每次优化至当天24:00。** 它不是后来测试的“24小时滚动前瞻窗口”；后者按用户要求不纳入待提交区，不混用其数值。题目每次提供24小时预报，本版本只使用其中当日部分，论文必须说明这一截断近似。

普通购电按最终有效计划电量计费；每次调整与上一版有效计划比较，增减均累计 `0.5 × 交付时段电价 × 变更电量绝对值`。实际总费为普通购电费＋调整费＋5倍紧急购电费。初始6000kWh用于1月热启动；每日不重置，内部终端储电量仅要求不低于1200kWh。

## 结果

统计期为2025-02-01至2025-12-31，共334天，1月为热启动。

| 指标 | 数值 |
| --- | ---: |
| 普通购电费 | 13,072,986.73元 |
| 调整费 | 583,134.56元 |
| 紧急购电费 | 196,051.52元 |
| 总费用 | **13,852,172.81元** |
| 库存价值修正后费用（比较指标） | 13,853,768.63元 |
| 普通购电量 | 21,116,517.11kWh |
| 紧急购电量 | 41,158.75kWh |
| 已付费未使用网电 | 736,573.35kWh |
| 统计期初／期末储电量 | 3,910.13／1,595.93kWh |
| 实际改变计划的更新次数 | 869次／1002次可更新机会 |

相对点预报滚动方向1，总费用减少658,698.89元（4.54%）。方向3仍比本主模型少154,917.31元（1.12%）；选择方向2是基于与前两问的衔接、解释和复现成本，并不表示方向2费用最低或已证明其统计稳定性优于方向3。上述均为时间顺序回测结果。

## 文件与复现

- `summary_tables.csv`：方向2总费用、能量和库存指标；金额单位元，电量单位kWh。
- `daily_summary.csv`、`periods.csv`：334天逐日及分期结果。
- `issue_summary.csv`：各发布时间的调整汇总。
- `paper_dates_summary.csv`：3月20日、6月21日、9月23日、12月21日四个日期的汇总。
- `paper_dates_dispatch.csv`：上述日期576条10分钟实际执行记录。该表逐行费用不含计划调整费，调整费应从下表按发布日期汇总后加入。
- `paper_dates_plan_versions.csv`：四日期0/6/12/18时计划版本、旧值、新值及逐时调整费。0时旧计划留空；各版本只含尚未执行时段；`slot=0`表示0:00—0:10，`interval_end`为区间终点。
- `manifest.json`：来源、参数、SHA256和本次提取核验。完整原始账本不重复进入Git，可重跑生成。
