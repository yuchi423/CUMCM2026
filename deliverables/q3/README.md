# 第三问方向3：连续误差场景主模型结果

2026-09-13用户将第三问主模型改为方向3 `rolling_scenario`。本包直接提取已审计实验 `experiments/q3-models-20260911-04` 的既有结果，没有重新求解或根据结果调参。完整赛题工作簿为 [`output/result3.xlsx`](../../output/result3.xlsx)。

## 模型思路

模型在每天0:00形成初始计划，并在6:00、12:00、18:00读取最新光伏预报和真实储电量，只调整尚未执行时段。未使用DP；候选计划由LP生成，必要时使用MILP处理物理互斥。

1. 负载采用过去35天同星期均值；同星期样本少于2个时退回过去7天均值，当日预测在0时固定。
2. 光伏采用当前发布的最新预报，从发布时刻最近已观测值到未来整点做线性插值，转换为10分钟电量。这是模型近似。
3. 每次更新时间保留最近8条连续净负荷预测残差轨迹，生成点预测、0.8分位余量、各残差轨迹和“保持上一版计划”等候选。
4. 所有候选用同一因果物理执行器在历史场景上回放，按 `场景平均库存修正费用 + 0.25 × (90% CVaR - 场景平均费用)` 评分。固定计划跨场景共享，避免场景内电池提前看见未来后分别采取理想动作。
5. 真实执行沿用光伏先负载、再充电、再弃光规则，网电可补充充电；缺口先放电再按5倍价格紧急购电。储电量跨日连续。

**本包窗口：每次优化至当天24:00。** 它没有采用后来单独测试的跨午夜24小时前瞻窗口。连续残差场景是有限历史样本下的候选筛选，不等于已识别真实误差分布，也不声称全局最优。

普通购电按最终有效计划电量计费；每次调整与上一版有效计划比较，增减均累计 `0.5 × 交付时段电价 × 变更电量绝对值`。实际总费为普通购电费＋调整费＋5倍紧急购电费。初始6000kWh用于1月热启动；每日不重置，内部终端储电量仅要求不低于1200kWh。

## 结果

统计期为2025-02-01至2025-12-31，共334天，1月为热启动。

| 指标 | 数值 |
| --- | ---: |
| 普通购电费 | 12,959,330.77元 |
| 调整费 | 641,629.19元 |
| 紧急购电费 | 96,295.54元 |
| 总费用 | **13,697,255.50元** |
| 库存价值修正后费用（比较指标） | 13,697,787.53元 |
| 普通购电量 | 20,981,222.55kWh |
| 紧急购电量 | 19,362.54kWh |
| 已付费未使用网电 | 622,412.95kWh |
| 统计期初／期末储电量 | 2,119.62／1,348.09kWh |
| 实际改变计划的更新次数 | 758次／1002次可更新机会 |

相对方向2，方向3总费用减少154,917.31元（1.12%），紧急购电量减少21,796.20kWh。2—4月、5—8月、9—12月费用分别为329.56万元、508.59万元和531.57万元；三个阶段均完成连续回放。上述均为时间顺序回测结果，不是外部盲测。

## 文件与复现

- `summary_tables.csv`：方向3总费用、能量和库存指标；金额单位元，电量单位kWh。
- `daily_summary.csv`、`periods.csv`：334天逐日及分期结果。
- `issue_summary.csv`：各发布时间的调整汇总。
- `paper_dates_summary.csv`：3月20日、6月21日、9月23日、12月21日四个日期的汇总。
- `paper_dates_dispatch.csv`：上述日期576条10分钟实际执行记录。该表逐行费用不含计划调整费，调整费应从下表按发布日期汇总后加入。
- `paper_dates_plan_versions.csv`：四日期0/6/12/18时计划版本、旧值、新值及逐时调整费。0时旧计划留空；各版本只含尚未执行时段；`slot=0`表示0:00—0:10，`interval_end`为区间终点。
- `manifest.json`：来源、参数、SHA256和本次提取核验。完整原始账本不重复进入Git，可重跑生成。
- `workbook_validation.json`：官方模板哈希、成品哈希、行数、费用及表头核验。
- `output/result3.xlsx`：按官方模板填写的完整334天结果；表头保持官方原样，数据使用模型 `slot 0～143` 顺序。
